# Build a Personal Portfolio Website

## What I Want
A modern, beautiful personal portfolio website that showcases projects and skills.

## Features

### Landing / Hero Section
- A stunning animated hero section with a greeting message
- Typing animation effect for different titles (e.g., "Developer", "Designer", "Creator")
- A call-to-action button that scrolls to the projects section
- Subtle particle or gradient animation in the background

### About Section  
- A brief bio section with a profile image placeholder
- Skills displayed as animated progress bars or tags
- Clean, readable typography

### Projects Section
- A grid of project cards (use 3-4 placeholder projects)
- Each card has: title, description, tech tags, and links
- Hover effects with smooth animations
- Filter buttons by technology (e.g., "All", "Web", "Mobile", "AI")

### Contact Section
- A simple contact form (name, email, message)
- Social media icon links (GitHub, LinkedIn, Twitter)
- Form doesn't need a real backend — just the UI

## Design Requirements
- Dark theme with accent color (purple/blue gradient)
- Fully responsive (mobile, tablet, desktop)
- Smooth scroll navigation
- Modern glassmorphism effects
- Clean, minimal aesthetic

## Tech Stack
- Pure HTML, CSS, and JavaScript (no frameworks needed)
- Single page application
- All in one folder: index.html, style.css, script.js

## Target
This should look like a professional developer's portfolio that would impress at first glance.
